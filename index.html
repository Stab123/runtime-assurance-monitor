When the Envelope Suffices — Runtime Assurance

Sami Bey

Embedded runtime assurance monitor — executable prototype and reproducible falsification campaign.

This page presents scientific work by Sami Bey on runtime assurance for autonomous embedded decision systems. The repository provides an executable assurance-monitor prototype, an auditable decision trace, and a reproducible Monte Carlo campaign.

Main result

Negative result: in the tested scenario, the safety envelope alone reaches zero violations over 300 draws. Hardening based on estimation uncertainty does not prevent additional violations and reduces availability.

The result is reported as a falsification result rather than as evidence for a claimed benefit. Code, configurations, correction history, figures and campaign outputs are maintained in the public repository for reproducibility.
