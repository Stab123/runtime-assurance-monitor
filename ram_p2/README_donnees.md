# Fichiers de résultats

Les fichiers `resultats_p2_1.json`, `resultats_p2_2.json` et
`resultats_p2_3.json` sont les sorties brutes des campagnes. Ils contiennent
les empreintes SHA-256 du code au moment de l'exécution : toute réécriture,
même d'un espace, les invaliderait.

Ils doivent être déposés **tels qu'ils ont été produits**, depuis
l'environnement d'exécution. Vérifier le champ `version_config` de chacun
avant de le renommer :

| version_config | nom de fichier        |
|----------------|-----------------------|
| P2.1           | `resultats_p2_1.json` |
| P2.2           | `resultats_p2_2.json` |
| P2.3           | `resultats_p2_3.json` |

Le tableau agrégé de chaque campagne est reproduit dans le README principal.
